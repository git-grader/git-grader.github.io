GitGrader is an open-source, self-hostable platform for courses that accept programming assignments over Git: students push work through SSH, the service records an immutable submission and grades it in an isolated container, and instructors manage coursework through a web interface.

How it works

A trusted path from push to proof

Every accepted push becomes a durable submission and a reproducible grading event — nothing runs on the host, nothing is graded twice differently.

01

Push

Students submit over SSH with registered keys — the workflow they already use.

02

Capture

The push is admitted and recorded as an immutable, append-only submission.

03

Run

A queued job grades the code in an isolated Docker sandbox with hidden tests.

04

Grade

Scoring is transparent: tests passed / tests total, recorded with the run.

05

Review

Students get a result link; instructors review evidence in the web app.

Principles

Built for courses that need control

Git-native

Submission is a git push. No upload portals, no zip files, no plugins.

Auditable

Append-only submissions, grading runs, and audit events. The record is durable and reviewable.

Isolated

Grading runs in controlled containers with runtimes pinned by image digest — never on the host.

Self-hostable

Your institution keeps operational and data control. PostgreSQL, Docker, LDAP — no external services.

Features

Evidence, not promises

  • Git-over-SSH admission with registered-key and SSHSIG signature checks
  • Versioned templates and hidden test suites students cannot read
  • Runtimes pinned by image digest for reproducible grading
  • Append-only submissions and grading runs — the record cannot be rewritten
  • PostgreSQL-backed queue and container runner isolation
  • Opaque result tokens, LDAP instructor auth, audit events, rate limits

Quick start

Deploy your own grader

# clone, configure, start
git clone https://github.com/git-grader/gitgrader
cd gitgrader
cp .env.example .env        # set passwords + public HTTP/SSH names
docker compose up -d
scripts/verify-install.sh   # readiness, API meta, SSH checks

Compose starts PostgreSQL and the app. Full details in the installation guide — including building the image locally with ./mvnw spring-boot:build-image.
